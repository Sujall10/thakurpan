# Thakur Pan — Night Market

Open `index.html` to view the site (Home, About, Menu, Contact).

## What's new in this version
- **Intro loader** — `video/loader.mp4` (+ `.webm` fallback) plays on the first visit of a session, scaled to fit any screen. Includes a Skip button, a still-logo fallback and reduced-motion support.
- **Logo** — transparent versions in `brand/` (cream for dark backgrounds, ink for light ones). Used in the header, footer, hero stamp, page transitions and loader.
- **Favicon / URL icon** — `favicon.ico`, `icons/icon-{16,32,48,96,144,192,512}.png`, `apple-touch-icon.png`, `site.webmanifest`.
- **Address** corrected to Shop 51–53. **Hours**: Mon–Sat 9:30 AM–11:30 PM, Sunday 9:30 AM–2:30 PM (also drives the "Open now" chip and Google structured data).
- **Google bio** — new title, description and schema.org data (`slogan`, opening-hours specification, logo).
- **Cinematic photos** — graded shop photos in `img/cine-*.jpg`, shown in the new "Inside Thakur Pan" section and page banners; `img/og-cover.jpg` is the social/Google share image.

Fonts load from Google Fonts (internet connection required).
